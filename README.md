村民意识(The Awakening of the Villagers)概述:

此模组加强了村民的行为逻辑。

注意：本模组目前为测试版本，如遇 BUG 请及时反馈。

支持 Java 1.21.1 / Fabric 的模组，为村民添加了多种全新的行为与能力。

战斗

无业村民与绿袍村民会主动攻击附近的敌对生物，也会对杀死其他村民的玩家进行反击。

村民可以使用剑、弓、弩，可穿戴装备。

使用剑时，有一定概率格挡伤害，格挡概率取决于剑的基础攻击力（木剑 40%、石剑 50%、铁剑 60%、钻石剑 70%、下界合金剑 80%，暂时不支持其他 Mod 的剑）。

当村民手持斧且目标玩家正在持盾格挡时，会击破玩家的盾牌。

远程攻击

村民可以使用原版及部分模组中的弓和弩，支持普通箭、药水箭、光灵箭。村民会尽可能的避免误闯其他村民和铁傀儡。

伐木

无业村民或屠夫会寻找并砍伐树木，收集掉落的木材与树苗，并在原处补种树苗。

灭火

村民会扑灭附近有蔓延风险的火焰，并帮助着火的村民。当村民自身着火时，会立即扑灭周围 3×3×3 范围内的所有火焰。

仓储管理

村民会与可见的容器交互，存放多余的物品，取出容器中缺少的物品，并自动装备更好的盔甲。

职业掉落

部分职业村民在工作时会额外掉落物品。例如盔甲匠掉落附魔盔甲，屠夫掉落原木，农民掉落面包，制箭师掉落箭或弓，图书管理员掉落附魔书，石匠掉落石头或圆石，牧羊人掉落羊毛。(但是他们往往会快速捡起这些掉落物)

合成与附魔

合成专家模块使普通村民能够使用铁锭合成铁甲。盔甲匠可制作并分发多种材质的盔甲，工具匠可应用附魔书。

工程建造

村民可以读取内置的.litematic 投影文件，消耗绿宝石在附近建造建筑。支持内置及外部投影。

绿袍加强

绿袍村民现在拥有 5 级交易，交易物品包括泥土、圆石、绿宝石、钻石、下界合金碎片等，且交易次数为无限。绿袍村民死亡时按等级掉落大量绿宝石块。

配置界面

提供游戏内 GUI（默认按键 O），可开关各功能模块。

注：该功能暂时有技术性问题导致无法使用。
